Una vista lo devuelve así: {% extends "piezas/ventana.html" %} {% block titulo %}Nuevo pedido{% endblock %} {% block cuerpo %} ...campos... {% endblock %} {% block pie %}{% endblock %} El botón que solo cierra dice "Cancelar"; una ventana sin nada que cancelar lo cambia con {% block cerrar %}Cerrar{% endblock %}. Todo va dentro de un formulario. `accion` es la dirección a la que se envía y `objetivo`, dónde se dibuja la respuesta (por defecto, la misma ventana, para mostrar los errores). La vista responde con config.ventanas.responder_ventana: dentro de la ventana si la pidió HTMX, o como página completa si se abrió el enlace sin JavaScript. Como página (`en_pagina`, lo pone piezas/pagina_ventana.html) no hay X: no hay ventana que cerrar, y el título ya está arriba en la hoja (si no hay `titulo_pagina`, va aquí sin la X). "Cancelar" es un enlace de verdad que vuelve a `volver` (lo calcula responder_ventana). {% endcomment %}
